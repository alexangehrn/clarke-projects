We want everyone to be able to use this website. It is designed and tested with the Web Content Accessibility Guidelines (WCAG) 2.2, level AA, as our target: it can be used with a keyboard, works with screen readers and browser zoom, gives images text descriptions, and turns off movement when your device asks for reduced motion.
